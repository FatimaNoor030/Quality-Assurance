## Assignments Completed

### Assignment 01 — Requirement Analysis

The first assignment focused on understanding and documenting requirements for an Online Book Store system.

Key areas covered:

* Functional Requirements
* Non-Functional Requirements
* User Stories
* Acceptance Criteria using Gherkin
* Sprint Planning
* Requirement Documentation

---

### Assignment 02 — Test Plan and Test Cases

The second assignment focused on applying the refined requirements to manual testing activities for the Online Book Store system.

Key areas covered:

* High-Level Test Plan
* Test Case Design
* Functional Test Cases
* Test Case Classification
* Test Suite Organization
* Test Case Management using Testworthy
* Test Execution
* Execution Status Tracking
* Test Execution Reporting
* Test Case Export

Test cases covered core workflows including:

* User Registration
* User Login
* Book Catalog
* Book Search
* Book Details
* Shopping Cart
* Checkout
* Order Confirmation
* User Account Management

---

### Assignment 03 — Bug Identification and Reporting

The third assignment focused on exploring a provided buggy web application and identifying unexpected behaviors and defects.

The testing activities covered different areas of the application, including:

* Navigation
* Forms
* Buttons
* Search Functionality
* Input Validation
* Page Layout
* Links
* Error Messages

The assignment included identification and documentation of:

* Functional Bugs
* UI / Visual Bugs
* Validation Bugs
* Usability Issues

The bug reports included:

* Bug ID
* Title / Summary
* Description
* Steps to Reproduce
* Expected Result
* Actual Result
* Severity
* Priority
* Environment
* Status

Release notes were also prepared to summarize the identified issues and provide an overall view of the application's quality.
